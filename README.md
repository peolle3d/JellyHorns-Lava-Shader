# Jelly-Lava-Shader
Procedural jelly shader with a lava lamp effect for Unity
🍓 Jelly-Lava Shader

A customizable procedural jelly shader for stylized 3D characters and VTuber models.

Originally created for jelly antlers inspired by lava lamps.

Features

Animated lava-like blobs

Customizable jelly and blob colors

Adjustable transparency and gloss

Optional outer and blob outlines

Adjustable highlights

Blob movement, size and merging controls

No textures required

Compatibility

Unity 2021.3

Built-in Render Pipeline

Warudo Mod Tool

Installation

Download the .shader file.

Import it into your Unity project's Assets folder.

Create a new Material.

Select Custom/JellyHorns Lava V4 DepthFix.

Assign the material to your model and adjust the settings.

Notes

The shader's appearance may vary depending on lighting, transparency and rendering environment.
